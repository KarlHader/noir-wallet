## Install the extension

Install Noir Wallet from the [Chrome Web Store](https://chromewebstore.google.com/detail/noir-wallet/mfoghjbpfanobmnoemoepenjjcmfpmdn) and pin it from Chrome's extensions menu. The official extension ID is `mfoghjbpfanobmnoemoepenjjcmfpmdn`.

<Callout type="warn" title="Avoid unofficial downloads">
  Do not install wallet packages sent through direct messages or download an unpacked extension from
  an unknown source.
</Callout>

## Create a new wallet

Choose **Create Wallet**, set a local password, and write down the recovery phrase in order. Keep the backup offline and complete the phrase check before funding the wallet.

## Restore an existing wallet

Choose **Import Wallet** to restore from a recovery phrase. For ZEC history, start the scan from your first Zcash transaction date or an earlier block height. For private keys, hardware devices, or sync help, see [Install and set up](/wallet-guide/install-and-setup).
