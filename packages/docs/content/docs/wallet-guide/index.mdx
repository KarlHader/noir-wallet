## Wallet modes

Select a balance card on Home before choosing an action. The cards and actions available depend on the account, enabled networks, and hardware support.

| Mode | What it holds | Where to start |
| --- | --- | --- |
| **Public** | Transparent ZEC and public EVM balances | Use **Send** or **Receive** for standard on-chain transfers. |
| **Shield** | Native shielded ZEC and eligible NEAR Confidential assets | Use **Receive** or open **Providers** to choose a [Shield provider](/wallet-guide/shielded-funds). |
| **Incognito** | A separate EVM account for eligible software wallets | Select **+ Incognito** to set it up, then use **Deposit** or **Withdraw** to move funds between Public and Incognito. A direct transfer can publicly link the addresses. |

## Help and project information

Open **Settings > Help** to export diagnostic logs or contact support. **Settings > About** shows the installed version, build date, and package license. GitHub, X, and Telegram links are available in About and at the bottom of Settings.
